* Design
- Symmetry invariant :: neither forge is the master. The only asymmetric rule (Forgejo wins divergence) is replaced by: true divergence is *recorded, never auto-resolved*; both sides are left untouched until a human pushes the winning SHA to one forge, after which normal fast-forward sync converges the other side.
- Plan output for divergence :: zero actions for the ref plus one conflict of kind =git-ref-divergence= carrying both SHAs.
- Force capability removed :: =Action.Force= and the =--force= push flag are deleted from the sync path; a losing race against a concurrent push is now rejected by the receiving forge as a non-fast-forward and surfaces as a reconciliation error instead of destroying history.
- Unchanged :: one-side-missing refs copy to the missing side in either direction; ahead refs fast-forward in either direction; refs are never deleted; dry-run mutates nothing; ancestry failure aborts planning.
- Compatibility :: conflict =Kind= changes only for new rows; schema and JSON shape unchanged; historical =git-ref-override= rows remain valid audit records.
- Rejected alternatives :: bot-authored merge commits (requires committer identity and new commits on the forges; far beyond smallest coherent change); committer-timestamp last-write-wins (forge-independent, gameable, still silently drops one side); keeping Forgejo-wins (precisely what issue #6 removes).

* Adversarial review
- Divergences no longer self-heal: accepted operator contract; the conflict record with both SHAs is the resolution surface, convergence happens through ordinary fast-forward once a human aligns one side.
- TOCTOU between fetch and push: pre-existing and non-atomic; without force the worst case is a rejected non-fast-forward push with a loud, retryable error — strictly safer than the current forced overwrite.
- Conflict accumulation: deduped by the store on both SHAs; a changed SHA pair records one new row, matching release-conflict behavior.
- Restart/idempotency: planning is pure over fetched refs; repeated runs produce identical plans and deduped conflict rows.
